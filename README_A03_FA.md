# مدرسه‌یار — اندروید معلم A03 — اجرای رابط منتخب شماره ۶ (نسخه آزمایشی)

این بسته بر اساس A02-FIX03 است و با **سورس وب مدرسه‌یار در هاست کاری ندارد**. سورس اپ Android Studio + GitHub Actions در ریشه ZIP قرار دارد.

## طراحی

- راست‌به‌چپ؛ زمینه روشن، سفید، آبی ملایم، رنگ‌های مکمل سبز/هلویی/یاسی؛ کارت‌ها و آیکون‌های هماهنگ
- خانهٔ اختصاصی معلم در فایل `app/src/main/assets/teacher_dashboard.html`
- مرکز «بیشتر» با دسته‌بندی امکانات در `app/src/main/assets/teacher_more.html`
- نوار پایین بومی اندروید: خانه، کلاس‌ها، حضور، نمرات، بیشتر
- بخش‌های عملیاتی همچنان همان صفحات واقعی `/app/` هستند، با تغییرات بصری محدود و غیرمخرب در `teacher_portal.css`
- دکمه «تمام ابزارهای پنل معلم در وب» برای دسترسی به منوهای اصلی تا تکمیل کامل صفحه‌های اختصاصی موبایل

**توجه:** تصویر اصلی طرح ۶ به طور کامل در فایل‌های فعلی موجود نبود؛ A03 پیاده‌سازی طبق مشخصات ثبت‌شده آن است. برای تطابق پیکسلی با تصویر قبلی باید پیش‌نمایش این نسخه با همان عکس اصلی مقایسه شود.

## اتصال به امکانات واقعی

**داشبورد مستقل از سایت است اما عملیات واقعی مستقیماً در پنل معلم سایت انجام می‌شود**: معلم در `/app/` احراز هویت می‌شود، صفحه Home اختصاصی اندروید جایگزین صفحه Home وب می‌شود و کلیک روی امکانات از طریق کنترل‌های موجود در DOM وب و با نقش `teacher` همان بخش را باز می‌کند. این نسخه هیچ REST API ساختگی، نمره ساختگی، داده محلی دوم یا مجوز تازه ندارد.

نمونه مسیریابی‌ها:

- «کلاس‌های من» به `myTeaching` در پنل وب
- «حضور» به `classroom`
- «دفتر نمره» به `gradeCenterT07`
- «مرکز تکالیف» به `p65-homework-link` و ماژول قبلاً نصب‌شده `MadreseyarHomeworkP652`
- «بانک سؤال» به `p6312-independent-exam-link` و ماژول مستقل بانک سؤال موجود
- «آزمون‌ها»، «ساخت آزمون»، «تصحیح»، «گزارش‌ها» به همان دکمه‌های وب
- اگر منوی قابل‌استفاده برای یک ماژول در نسخه فعلی وب موجود نباشد، اپ پیام می‌دهد و از «بیشتر → تمام ابزارهای پنل معلم در وب» می‌توان آن را بررسی کرد. به‌جای نمایش صفحه بی‌عمل، خطای مشخص نشان داده می‌شود.

## ورود و حفظ امنیت

ورود اولیه از صفحه رسمی `/app/` انجام می‌شود و پس از ورود صحیح حساب معلم، داشبورد اختصاصی باز می‌شود. BiometricVault و Android Keystore، درخواست بازگشایی قفل، و چک سروری نشست از A02-FIX03 تغییر نکرده‌اند. گذرواژه معلم در اپ ذخیره نمی‌شود. ورود با حساب غیرفعال/نقش دیگر به اپ معلم مجوز اضافه نمی‌کند. خروج امن توکن اثر انگشت ذخیره‌شده را نیز پاک می‌کند. `FLAG_SECURE` برای حفاظت از صفحه حفظ شده است.

## نصب در GitHub

1. فایل ZIP کامل A03 را استخراج و محتویات آن را در ریشه مخزن فعلی Github جایگزین/اضافه کن. **پوشه `.github` را فراموش نکن.**
2. بعد از Commit به `Actions → Build teacher Android APK (test) → Run workflow` برو.
3. در صورت موفقیت Build، Artifact با نام `Madreseyar-Teacher-A03-Design6-Debug-APK` حاوی APK آزمایشی خواهد بود.
4. APK را روی دستگاه آزمایشی نصب کن، با حساب آزمایشی معلم وارد شو و کارهای آموزشی واقعی را تست کن. اگر نسخه قبل با امضای debug متفاوت نصب است ممکن است لازم باشد حذف شود.

## محدودیت‌های مهم

- در این محیط Android SDK / Gradle جهت ساخت واقعی APK موجود نیست. کنترل‌های ایستای مسیرها، HTML و سازگاری با FIX03 اجرا شده‌اند، اما **بیلد APK و کارکرد گوشی هنوز تأیید نشده**.
- A03 پوسته مستقل + ناوبری اختصاصی است؛ همه فرم‌های وب هنوز به UI بومی اندروید تبدیل نشده‌اند. برابری عملی همه ماژول‌ها نیازمند آزمایش تک‌تک عملیات است.
- فایل و دوربین، چاپ PDF، پنجره آزمون/بانک سؤال، تقویم شمسی، ثبت نمره، ذخیره تکلیف، بازگشت، بیومتریک و logout باید روی گوشی واقعی تست شوند.
- اپ نیاز به اتصال HTTPS سرور دارد. هیچ فایل هاست، `server.mjs`، دیتابیس و داده زنده مدرسه‌یار در این بسته تغییر نکرده‌اند.

## بازگشت

در فایل Patch کوچک، پوشه `ROLLBACK_TO_A02_FIX03` فایل Java قبلی و Gradle قبلی را دارد. در نسخه کامل نیز با بازگشت به Commit قبلی GitHub، A03 حذف می‌شود. برای بازگشت به حالت قدیمی، کل تغییرات A03 شامل سه asset و UI جدید را برگردان. سورس مادر وب مستقل از این کار است.
