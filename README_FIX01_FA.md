# مدرسه‌یار — معلم اندروید A03-FIX01 — اصلاح عکس سیاه اسکرین‌شات

## علت قطعی
در نسخه A03، فایل `MainActivity.java` داخل `onCreate()` از `getWindow().addFlags(WindowManager.LayoutParams.FLAG_SECURE);` استفاده می‌کرد. این پرچم ضبط و اسکرین‌شاتِ کل صفحه را در اندروید مسدود و تصویر سیاه ایجاد می‌کند.

## رفتار نسخه اصلاح‌شده
- روی صفحه **باز و فعال پس از ورود**، `FLAG_SECURE` برداشته می‌شود و اسکرین‌شات عادی قابل گرفتن است.
- هنگام **صفحه قفل اثر انگشت**، آغاز برنامه قبل از بازگشایی، یا رفتن برنامه به **پس‌زمینه**، `FLAG_SECURE` دوباره فعال می‌شود.
- ورود، داده و توکن معلم، دوربین، فایل، منوها و ارتباط با سرور تغییری نکرده‌اند.
- چون اسکرین‌شاتِ صفحه دارای نام و نمره دانش‌آموز ممکن می‌شود، تصاویر آزمایشی را فقط پس از پوشاندن اطلاعات شخصی به اشتراک بگذارید.

## نصب روی GitHub
اگر A03 را قبلاً در مخزن گذاشته‌اید، فقط این سه فایل را از پوشه `INSTALL` پچ کوچک جایگزین کنید:
1. `app/src/main/java/ir/scooljavanrood/madreseyar/teacher/MainActivity.java`
2. `app/build.gradle`
3. `.github/workflows/build-debug-apk.yml`

بعد از Commit، در GitHub Actions گزینه `Build teacher Android APK (test)` را اجرا کنید. نام Artifact جدید `Madreseyar-Teacher-A03-FIX01-Debug-APK` خواهد بود. با APK جدید، تست اسکرین‌شات بگیرید.

**نکته درباره نصب:** در GitHub Actions هر بار امضای آزمایشی ممکن است تغییر کند. اگر نصبِ نسخه جدید روی نسخه قبلی با `INSTALL_FAILED_UPDATE_INCOMPATIBLE` متوقف شد، پس از اطمینان از داشتن اطلاعات ورود، نسخه قبلی را حذف و APK جدید را نصب کنید؛ تنظیمات محلی و فعال‌سازی اثر انگشت باید دوباره انجام شوند.

## محدوده تغییر و تست
صرفاً سورس Android؛ هاست، `server.mjs` و پایگاه داده بدون تغییر. بررسی ایستای ساختار Java، ZIP و نقاط تغییر وضعیت پنجره انجام شده؛ ابزار SDK برای کامپایل APK در این محیط موجود نیست و موفقیت روی گوشی باید تست شود.
